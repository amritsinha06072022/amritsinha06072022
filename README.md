## What I have Built

### Quantitative Finance
- [black-scholes-options-pricer](https://github.com/amritsinha06072022/black-scholes-options-pricer) — a Black-Scholes-Merton options pricer with live market data, an implied-volatility solver, and an interactive dashboard. **[Live demo](https://black-scholes-options-pricer-amritsinha.streamlit.app/)**.
- [LOB-imbalance-predictor](https://github.com/amritsinha06072022/LOB-imbalance-predictor) — predicts short-horizon crypto price direction from limit order-book imbalance using real Binance data, with leakage-safe, purged time-series validation.
- [momentum-trading-backtester](https://github.com/amritsinha06072022/momentum-trading-backtester) — a from-scratch quantitative backtester testing whether a moving-average momentum strategy beats buy-and-hold.

### Applied AI / LLMs
- [Order-extractor](https://github.com/amritsinha06072022/Order-extractor) — parses unstructured invoice PDFs and order emails into clean, structured JSON using Python and the Claude API.

### Machine Learning
- [chess-match-tactical-analysis](https://github.com/amritsinha06072022/chess-match-tactical-analysis) — an ML pipeline that predicts chess win-probability from a single mid-game position, and rediscovers the classical piece values from game outcomes alone, using a Lichess Open Database of 50,000 games and 195,000 board positions.

### Algorithmic Engineering
- [chess-engine](https://github.com/amritsinha06072022/chess-engine) — a chess engine built from scratch with negamax and alpha-beta search, quiescence search, a transposition table, and positional evaluation, playable via a pygame GUI or the terminal.

### Mobile Application Development
- [London-Underground-Path-Finding-Android-Application](https://github.com/amritsinha06072022/London-Underground-Path-Finding-Android-Application) — an Android app that finds the fastest route between Underground stations using Dijkstra's algorithm over an offline SQLite graph of the Tube network.
